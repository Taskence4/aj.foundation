# AJ Foundation — Website Image Requirement Sheet

This sheet covers every production image slot in the current homepage. The dimensions below are recommended source dimensions, not rendered CSS sizes. They provide enough resolution for retina displays and responsive cropping.

## Global production direction

- Visual style: credible documentary photography, warm natural light, authentic Indian context, restrained maroon/crimson accents, realistic skin texture, and candid human interaction.
- Representation: adults of varied ages, genders, and backgrounds; trainers, volunteers, institutional stakeholders, employers, and programme participants.
- Dignity and privacy: use real participants only with written consent. Otherwise use models, hands, silhouettes, over-the-shoulder angles, or non-identifiable wide shots.
- Avoid: visible prison numbers, handcuffs, bars used as visual clichés, distressed or humiliated expressions, political branding, readable private documents, logos, watermarks, and AI-generated text.
- Delivery: use sRGB. Supply photographic assets as high-quality WebP plus the original JPEG/RAW. Use transparent WebP or PNG for the leader cutout.
- Cropping: keep important faces and hands away from the outer 12% unless a row specifies a larger safe area.
- JSON prompts: the full prompt objects are in [`image-generation-prompts.json`](./image-generation-prompts.json). The last column maps each slot to its prompt object.

## Export and naming checklist

1. Export each approved photograph as WebP at quality 82–88 and keep the source file separately.
2. Keep each delivered filename exactly as shown in the target-file column.
3. Target 250–700 KB per regular image and no more than 1.2 MB for hero/background images.
4. Strip GPS and unnecessary EXIF metadata before publishing.
5. Record photographer credit, subject consent, usage rights, and expiry/revocation conditions.
6. Do not publish generated images as documentary evidence of AJ Foundation’s real work; label or replace them with commissioned photography before public launch.
